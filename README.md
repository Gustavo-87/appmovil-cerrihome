## Instalación

1. Descarga el APK en el Android o transfiérelo desde tu Mac.
2. Ábrelo desde Archivos / Descargas.
3. Permite instalar desde esa aplicación cuando Android lo solicite.
4. Instala y abre Cerritos Home. Después puedes retirar ese permiso.

Es una compilación debug para pruebas con datos ficticios, no una publicación en Google Play. Los datos se guardan en cada teléfono y no se sincronizan. No ha sido validada en un teléfono físico.
